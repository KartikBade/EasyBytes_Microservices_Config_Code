1. Starting RabbitMQ: 
docker run -it --rm --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:4-management

2. Starting hookdeck (Make sure ConfigServer is running) (Run commands in PowerShell): 
hookdeck listen 8071 Source --cli-key 0iubtcxar4zudkon4mozpzufu44kn10ouk9jy9kvwlosue8hul

Can be found on: https://console.hookdeck.com/ -> Products -> Console

3. After running hookdeck command, a link will be generated. Set the generated link in GitHub webhooks. Make sure to append /monitor to the link.
